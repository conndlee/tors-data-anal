Each clip is one knot-tying window (needle through to knot tightened, 2 s extra at each end), shown at 3x speed. Count the throws: each wrap of the thread around the instrument, grasp of the tail and pull counts as one throw; a double wrap (surgeon's throw) is still one throw. Type the count; add a note if unsure. Counts are kept in this browser; use Export CSV to save them to results/sutures/knot_throws.csv.
