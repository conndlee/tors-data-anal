Keys and mouse

clickadd point on a tool
shift-clickadd point NOT on the tool (or right-click)
nstart the next tool (new object)
zundo last point
ssave this frame
esave as empty (no instrument in view)
← →previous / next frame

Label every robotic instrument: shaft, wrist and jaws. Do not include the retractor, teeth, needle or suture. Give each instrument its own object (key n), even when they touch. Unsaved changes are lost when you change frame.
