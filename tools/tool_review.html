Each card is a possible tool swap found in the rosbag. Frames run from 40 s before to 80 s after (click to enlarge). A swap shows the tool on one side leaving and a different tool coming back. Pick swap / no swap / unsure, and for swaps write the new tool (e.g. "needle driver", "grasper"). Then scan the contact sheets at the bottom for swaps the rosbag missed, and add them in the annotator (key t). Decisions are kept in this browser; use Export CSV to save them.
